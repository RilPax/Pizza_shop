# 🍕 Pizza-shop

Интерактивное веб-приложение для заказа пиццы, созданное с использованием современного фронтенд-стека.

---

## 🚀 Стек технологий
- **TypeScript** — строгая типизация
- **React** — компонентный UI
- **React Router** — маршрутизация
- **Redux** & **Redux Toolkit** — управление состоянием
- **Vite** — быстрая сборка и разработка
- **json-server** — эмуляция backend API

---

## 📦 Установка и запуск
1. **Склонируйте репозиторий:**
   ```bash
   git clone <url-репозитория>
   cd pizza-shop
   ```

2. **Установите зависимости:**
   ```bash
   npm i
   ```

3. **Запустите dev-сервер фронтенда:**
   ```bash
   npm run dev
   ```

4. **Запустите json-server (mock API):**
   ```bash
   npm run server
   ```

5. Откройте проект в браузере по адресу:
   ```
   http://localhost:5173
   ```

## 📡 API (json-server)
**Базовый URL:** `http://localhost:3001` (задаётся в `.env` → `VITE_BASE_URL`)

| Метод | URL                                     | Описание                    |
|-------|-----------------------------------------|-----------------------------|
| GET   | `/products`                             | Все товары                  |
| GET   | `/users/:id`                            | Авторизация по токену       |
| GET   | `/users?mail={почта}&password={пароль}` | Вход                        |
| POST  | `/users`                                | Регистрация                 |

Пример товара:
```json
{
  "id": "1",
  "title": "Пепперони",
  "description": "Классическая пицца с пикантной пепперони и моцареллой",
  "price": 47000,
  "category": "pizza",
  "image": "/images/products/pepperoni.jpg",
  "popular": true,
  "sizes": [
    { "size": 25, "price": 47000 },
    { "size": 30, "price": 59000 },
    { "size": 35, "price": 74000 }
  ]
}
```

Категории: `pizza`, `combo`, `snacks`, `drinks`, `desserts`, `sauces`.

## 📄 Возможности
- Главная в стиле промо-лендинга: hero, категории, популярное, акции, преимущества
- Меню с категориями, поиском, сортировкой по цене/популярности
- Выбор размера пиццы (25 / 30 / 35 см) с разной ценой
- Избранное (сердечки) — сохраняется в localStorage
- Корзина с количеством, работает и для гостя; при входе гостевая корзина переносится в аккаунт
- Промокод `PIZZA10` — скидка 10%, бесплатная доставка от 100 000 сум
- Оформление заказа (имя, телефон, адрес, способ оплаты) — доступно после входа
- Адаптивная вёрстка от 360px до десктопа
